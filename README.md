# Hiraya Sining - Digital Museum

A digital museum preserving and showcasing the rich cultural heritage of Philippine Art History. Explore masterpieces from the National Museum of Fine Arts through an immersive web experience.

## Features

- Interactive gallery with detailed artwork modals
- Responsive design for mobile and desktop
- Smooth page transitions and scroll animations
- Keyboard accessible navigation

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
